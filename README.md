# Rifteemo — legacy update bridge

Maintained by **Fargrim**. The primary distribution is now [Rifteemo releases](https://github.com/rafael00kl/rifteemo-releases), and the private source is [Rifteemo](https://github.com/rafael00kl/rifteemo).

This repository stays available because installed AlphaRune v0.2.6 clients and Setup executables still consult its release endpoint. Historical assets remain immutable. The [Rifteemo v0.2.7 migration release](https://github.com/rafael00kl/alpharune-releases/releases/tag/v0.2.7) is available and has been verified with the original v0.2.6 updater using public downloads.

- [English v0.2.6 report](REPORT-v0.2.6.md)
- [New distribution and installation instructions](https://github.com/rafael00kl/rifteemo-releases)

## Credits

Rifteemo began with the complete original [chorlick/alpharune](https://github.com/chorlick/alpharune) codebase, including the engine, architecture, cards, rules, tests and tools. The original creator/contributors remain credited and their Git history is preserved. [LouisCourrian/riftbound-cards](https://github.com/LouisCourrian/riftbound-cards) is a separate auxiliary card-data/errata reference. Riftbound, its cards and artwork belong to Riot Games and the credited creators. This is an independent community project.
